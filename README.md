## Installation
Step 1: Clone the repository
```js
git clone https://github.com/rifatperween/Secure-Transmission-.git
```
Step 2: Open the first terminal
```js
npm install
npm run dev
```
Step 3: Open second terminal
```js
pipenv install
pipenv shell
python app.py
```
